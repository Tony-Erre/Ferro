FERRO — Diario allenamenti (PWA)

CONTENUTO
- index.html: app completa
- manifest.webmanifest: impostazioni installazione
- sw.js: cache offline
- icon.svg: icona app

COME USARLA
1. Per provarla subito, apri index.html in un browser moderno. L'app usa localStorage sul dispositivo.
2. Per installarla come PWA e abilitare la cache offline, pubblica i file su un hosting HTTPS statico (ad esempio GitHub Pages) oppure avviala su localhost. I service worker non funzionano da file://.
3. Su Android, apri l'URL HTTPS in Chrome > menu ⋮ > Aggiungi a schermata Home / Installa app.
4. I dati restano nel browser di quel dispositivo. Non cancellare i dati del sito senza aver prima esportato un backup JSON dalla sezione Storico.
5. Usa "Backup completo JSON" per migrare i dati. Il CSV esporta le serie in formato tabellare.

PRIVACY
Nessun account e nessuna sincronizzazione cloud. I dati sono salvati localmente nel browser. Chiunque abbia accesso al dispositivo/browser potrebbe accedervi.

NOTA
Le schede iniziali sono esempi dimostrativi: sostituiscile con la scheda reale fornita dal tuo personal trainer. L'app non prescrive carichi né modifica il programma.
